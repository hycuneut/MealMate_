# MealMate V3

Prototype front-end nâng cấp từ MealMate: tên đăng nhập tùy chọn, avatar linh vật, nguyên liệu mở rộng + tự thêm, gợi ý món với bộ lọc thời gian/mức giá, dashboard + chatbot Mate, lịch tuần T2-CN, cộng đồng Reel/KOL/KOC/bạn bè, theo dõi 3 bữa/ngày + streak + biểu đồ 7 ngày, và nút đối tác GrabFood/ShopeeFood/Xanh SM Food.

## Chạy
Mở `index.html` bằng trình duyệt. `mealmate-logo.png` phải nằm cùng thư mục.

## Lưu ý
- Tên, nguyên liệu, bài đăng và check-in được lưu bằng localStorage trên trình duyệt, phù hợp prototype nhưng chưa phải hệ thống tài khoản/backend thật.
- Các nút đối tác đang dùng link trang chính thức; muốn có hoa hồng affiliate cần thay bằng tracking/affiliate link chính thức sau khi có thỏa thuận với đối tác.
- Chatbot Mate hiện là chatbot rule-based demo, chưa phải AI backend.
